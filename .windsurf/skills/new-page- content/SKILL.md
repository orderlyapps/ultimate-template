## Add New Page Component

1. Create a new content component importantly with only placeholder text.
2. Add the new component to the selected page component in the content section. The content component should be placed in a folder in src/content as per the AGENTS.md file.
3. Any path params should be fetched within the content component, not the page component
4. Create a new empty Zustand store for this page content in a store directory within the same folder as the new content component
